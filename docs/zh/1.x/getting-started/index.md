在本章 Fresh 文档中，你将了解该框架。你将学习如何创建新项目、在本地运行、编辑和创建页面、获取数据、处理用户交互，以及如何将项目部署到 [Deno Deploy](https://deno.com/deploy)。

本文档假设你已在系统上安装了最新版本的 [Deno](https://docs.deno.com/runtime/#install-deno)，并已[配置编辑器以配合 Deno 工作](https://docs.deno.com/runtime/getting_started/setup_your_environment/)。
