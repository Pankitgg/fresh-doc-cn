本文档的这一部分展示了与 Fresh 集成的模块或其他项目。这些集成可用于向你的项目添加功能。

## `fresh_charts`

Fresh charts 允许轻松将 [Chart.js][chart-js] 图表集成到你的 Fresh 项目中。它提供了一个 `Chart` JSX 组件，可用于在服务端和客户端渲染图表。

在线演示可在此处找到：https://fresh-charts.deno.dev/

模块文档可在此处找到：https://deno.land/x/fresh_charts

[chart-js]: https://www.chartjs.org/ "Chart.js"

## `fresh_marionette`

Fresh Marionette 允许你只需一次导入即可开始在 Fresh 项目中编写端到端浏览器测试。然后你可以在 GitHub Actions 工作流中运行这些浏览器测试。

模块文档可在此处找到：https://deno.land/x/fresh_marionette

在 GitHub Actions 工作流中运行测试的示例项目：https://marionette.deno.dev

Fresh Marionette 也适用于 VSCode！- https://youtu.be/OG77NdqL164
